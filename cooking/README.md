# Cooking

Cooking is one of the first places many people learn that technique is not decoration. It is the difference between stressful and calm, dangerous and safe, guessing and knowing.

This folder holds cooking classes, handouts, and teaching notes. Some are current. Some are archival. All of them should make the student less afraid of the thing in front of them.
